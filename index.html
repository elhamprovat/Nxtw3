Use a Binance API key with Spot Trading enabled and Withdrawals disabled. Start with a small sub-account balance. NxtW3 signs requests in your browser with Web Crypto and relays them through /api/exchange purely to bypass CORS — the proxy never sees your secret. This is still real money: nothing here has been through a third-party security audit, so trade size accordingly.
